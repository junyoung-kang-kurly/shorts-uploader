shorts-uploader

개인 유튜브 채널 주인이 직접 만든 영상을 자기 채널에 비공개로 올리는 개인용 스크립트입니다. 다른 사람에게 배포하거나 서비스로 제공하지 않습니다.

A personal script that uploads the channel owner's own videos to their own YouTube channel as private. It is not distributed or offered to anyone else.

개인정보처리방침 (Privacy Policy)

  • 쓰는 권한: YouTube 업로드(youtube.upload)와 재생목록 관리(youtube). 영상 업로드와 재생목록 추가에만 씁니다.
  • 받는 정보: Google 로그인 토큰뿐입니다. 업로드하는 사람의 컴퓨터에만 저장하고, 어떤 서버로도 보내지 않습니다.
  • 수집·공유: 개인정보를 수집하지 않고 제3자와 공유하지 않습니다. 광고·분석에 쓰지 않습니다.
  • 권한 철회: Google 계정 → 서드 파티 액세스에서 언제든 해제할 수 있습니다.

Google API에서 받은 정보는 Google API Services User Data Policy(제한적 사용 요건 포함)에 따라서만 사용합니다.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
